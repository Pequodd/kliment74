( 02 ) Как работает

Один цикл — шесть шагов

Шаг 01 / 06

  1. ( 01 )

    Загрузка

    Детали кладут в корзину из нержавеющей стали.

  2. ( 02 )

    Раствор

    Средство смешивается с водой, ТЭНы нагревают его. Крышка закрывается герметично.

  3. ( 03 )

    Мойка

    Таймер, вращение корзины, струи под напором сверху, снизу и сбоку.

  4. ( 04 )

    Ополаскивание

    Чистой водой — снять остатки средства.

  5. ( 05 )

    Сушка

    Естественно или горячим воздухом: отдельной сушки в мойке нет.

  6. ( 06 )

    Выгрузка

    Открыли крышку — детали чистые.
